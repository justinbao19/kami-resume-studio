不用打开网页，
也能完成一套可投递材料。

把旧简历、你授权的职业平台页面和目标岗位交给 Agent。Skill 会先建立有来源的职业画像，再用问答补齐最近经历，匹配语言与模板，最后生成主简历、ATS 安全版本和同风格求职信。

安装 Skill读取运行手册

DEFAULT BUNDLE

  1. 01候选人画像来源、时间线、证据状态
  2. 02岗位匹配简历中文或英文主版本
  3. 03ATS Companion必要时自动生成浅色单栏版
  4. 04求职信复用模板、语言与个人信息

适用方式

网页负责精修，Skill 负责从零开始。

你可以直接在编辑器中手填，也可以让 Codex、Claude Code 或支持 SKILL.md 的 Agent 在本地工作区运行完整流程。对 WorkBuddy、Hermes Agent 等环境，使用通用 Agent Skill 安装方式，或让 Agent 读取仓库内的 SKILL.md。

Skill 不依赖本站账号，也不会把职业资料上传到 Kami Resume。网页编辑器的数据保存在当前浏览器，Agent 工作流的资料与输出保存在你的本地工作区。

01 · WORKFLOW

先找齐事实，再决定如何表达。

  1. 01

    收集已授权资料

    读取旧 PDF/DOCX、粘贴文本、LinkedIn、BOSS 直聘、猎聘、58 同城、作品集、GitHub 与目标岗位 JD。

  2. 02

    建立证据画像

    合并职位、项目、技能、教育和时间线，并将事实标为 confirmed、sourced、inferred 或 conflict。

  3. 03

    用问题补齐最近工作

    优先询问旧简历尚未覆盖的最近岗位：职责、工作重心、影响范围、方法、数据结果和所有权边界。

  4. 04

    匹配岗位与叙事

    根据目标 JD 调整内容顺序和证据密度，只放大已确认优势，不复制没有经历支持的关键词。

  5. 05

    路由模板与语言

    从 14 类模板和 28 个明暗变体中选择主版本，浅色可选模板纸色、纯白或象牙白，并生成 ATS 安全版本。

  6. 06

    生成并检查交付包

    输出简历、求职信、未解决事实与匹配说明，再检查分页、链接、照片、内容密度和打印结果。

02 · TEMPLATE CATALOG

14 类模板，28 个明暗变体。

Agent 会依据岗位、行业、资历、表达个性和投递渠道自动路由。浅色模式可选模板纸色、纯白或象牙白。所有模板支持项目经历，参考型模板支持照片和同风格求职信。

03 · INSTALL

把 Skill 安装到你已经在用的 Agent。

下列命令安装的是本地 Skill 和工具，不是调用托管简历 API。

Claude Code 2.1.142+

/plugin marketplace add justinbao19/kami-resume-studio
/plugin install kami@kami

Codex

codex plugin marketplace add justinbao19/kami-resume-studio
codex plugin add kami@kami

通用 Agent Skill

npx skills add justinbao19/kami-resume-studio/plugins/kami -a universal -g -y

适用于读取通用 Agent Skill 目录的环境。WorkBuddy、Hermes Agent 等客户端的具体目录或导入方式以各自版本为准。

Claude Desktop

kami.zip

从 GitHub Releases 下载发布资产，在 Customize > Skills 中上传。不要使用 GitHub 自动生成的 Source code ZIP。

04 · DIRECT ORCHESTRATION

也可以直接调用确定性工作流。

python3 scripts/resume_workflow.py analyze candidate-dossier.json -o analysis.json
python3 scripts/resume_workflow.py questions candidate-dossier.json analysis.json -o interview-questions.json
python3 scripts/resume_workflow.py route candidate-dossier.json analysis.json -o route.json
python3 scripts/resume_workflow.py all candidate-dossier.json -o output/resume
输入

候选人 dossier、目标 JD、已确认问答，以及用户指定的语言或模板偏好。

输出

分析、问题、路由、主简历、ATS companion、求职信、可选推荐信与未解决事实。

质量边界

不编造指标，不夸大所有权，不绕过登录或验证码，不把私人职业资料写入公开仓库。
